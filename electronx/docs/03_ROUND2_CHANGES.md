## 1. API contract additions (Engineering implements, Design consumes)

* `GET /api/pulse/triggers` items add: `event_id, peak_ratio, neg_hours, actionable_count, exposed_count (distinct, hub-specific+ISO per X6), funded_not_trading, adv_at_stake`.
* `GET /api/pulse/triggers/{trigger_id}/accounts?view=actionable|all` (default `actionable`): adds top-level `counts:{exposed, funded_not_trading, actionable}`, `view`; rows add `rank, touch_value, hub (account's own), hub_match, health_state, account_fact` (e.g. "58 MW Houston load · funded 34 d · no trades yet" — internal, not customer-facing).
* `GET /api/pulse/events` (new, optional for frontend): `[{event_id, iso, hubs:[trigger_id], exposed, funded_not_trading, actionable, adv_at_stake}]` — the single source for event numbers used by CEO lever and Pulse banner.
* `GET /api/ceo/weekly`: KPI keys added `signed_cum, funded_cum` (each with `pace:{ytd, target, needed_weekly, run_rate_4w, projected_eoy}`), `adv_organic, speculator_share_adv_organic, hedger_adv, lp_share_adv`; `notional` becomes median daily notional with `note`; every KPI gets `board:bool` (exactly 6 true: funded_cum, active_rate, adv_contracts, cohort_activation, hedger_share_active, ercot_spread) and `prior_label`; `fee_revenue` gets a target (derive from ADV target × $0.25 × trading days) or status `info`. Top-level `lever:{event_id, iso, n, funded_not_trading, adv_at_stake, drafted, approved, queued, past_sla}`. `weekly_series` rows add `signed_cum, funded_cum`. Headline/decisions text uses lever numbers verbatim.
* `GET /api/activation/queue?view=today|all` (default `today`): Today = per-rep caps (AE/Strategic 12, RevOps 15, Head of GTM 5) with ≥50% hedger slots while below target; SLA breaches counted only on listed items. Items add `health_state, ramping:bool, owner_rep_id, owner_name`; summary adds `view, backlog`. Down-ranks: ramping × 0.3, DEFAULT rule × 0.25; urgency trigger boost only for stages eligible under X5.
* `GET /api/scoring/model` adds `honest:{gap_days, auc_gap, auc_unseen, baseline_name, baseline_auc, note}`; headline `auc` = `auc_gap`.
* `GET /api/funnel`: computed on **mature cohorts** (accounts with ≥ the step's p75 dwell + 30 d of age, or signed ≥ 90 d ago) — `steps[*].n_mature`; friction: only cards with `accounts_affected ≥ 5`, merged per (segment, step), top 6 by `adv_at_stake`, `step_label` human-readable, severity re-ranked so the seeded KYC-loop friction for UTILITY/CI_LOAD ranks high.
* Outreach: flags gain `id`; `POST /api/outreach/{id}/approve` body `{reviewer, cleared_flag_ids:[...]}` (409 if any caution not cleared, any block, or suppression now violated); `POST /api/outreach/{id}/reject {reviewer, reason}`; `POST /api/outreach/{id}/edit {subject, body}` → re-lint → returns full draft. `facts` for negative-price regime use `neg_hours` for `{event_hours}` so draft and Pulse agree.
* Comp-sim: totals and comparison rows add `pct_of_fee_revenue`; per-rep breakdown adds `accelerator_applied:bool`, `book_activation`.
* `GET /api/accounts/{id}`: `health.state` uses X2 vocabulary; `qbr` is `null` for accounts that never traded.
* New NBA condition code `ORDER_REJECTED_7D` (funded/first-trade, an `order_rejected` event in last 7 d and no qualifying trade since).
